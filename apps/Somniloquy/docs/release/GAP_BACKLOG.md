## 下一迭代切片

- 选择：生产身份 + 隐私/支持页面 + iOS 实体机整夜可靠性。
- 原因：这是从“功能完整 MVP”进入“可签名发布候选”的最短关键路径，也是当前 P0/P1 的共同前置。
- 不包含：账号、订阅、广告、社区、云同步、自动医疗分类或在线 AI。
- 完成条件：签名 Archive 预检通过；公开 URL 与应用内入口一致；真机核心录音矩阵有可复查证据；ASC 仍保持人工确认与非医疗定位。
