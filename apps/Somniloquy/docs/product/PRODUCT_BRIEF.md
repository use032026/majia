# Somniloquy 产品简报与 MVP PRD

评审日期：2026-10-08
范围：Flutter MVP + 独立功能审核 + iOS App Store 预检（不上传）。

## 产品论点

- 目标用户：对梦话、夜间声音与梦境回忆好奇，但不愿上传卧室录音、也不需要医疗诊断的成年人。
- 问题：整夜录音难以复听，自动健康评分难以验证；真正值得保留的是少量由用户亲自确认的声音、当晚背景和晨间回忆。
- 承诺：把本地录音整理成可人工核对、可删除、可回看的夜间卡片。
- 核心闭环：准备今晚 -> 明示录音与同室同意 -> 本地录音/环境校准 -> 候选声音时刻 -> 晨间试听与人工标签 -> 梦境笔记 -> 保存卡片 -> 历史回看/删除。
- 非医疗边界：不检测睡眠阶段、呼吸暂停或疾病，不给睡眠/鼾声分数，不提供治疗建议。

## 产品与发布假设

| 项目 | 决定或边界 |
| --- | --- |

## 非目标

- 云同步、账号、社交、公开分享、订阅、广告、在线 AI、HealthKit、通知和白噪音内容库。
- 自动判断“梦话/鼾声/呼吸暂停/睡眠阶段”或输出医学/健康分数。
- 模仿竞品的大圆开始按钮、总分仪表盘、排行榜或专有备份格式。
- 首版不承诺 Android 锁屏整夜录音、跨设备迁移、系统备份排除或临床用途。

## 信息架构

1. **今晚**：输入一条可选的晨间回忆提示，选择背景标签；主操作是“准备录音”。
2. **录音说明弹层**：说明本地处理、明显录音指示、同室人员同意与非医疗定位；取消不写数据。
3. **正在倾听**：持续红色录音指示、计时、校准/监听状态、当前音量和停止入口；页面退回需确认。
4. **晨间核对**：录音已停止；填写梦境笔记，逐条播放候选时刻并人工标为“可能的说话 / 呼吸声音 / 环境声音 / 不确定 / 忽略”。
5. **夜间卡片**：显示时间、背景、笔记和已确认时刻；原始候选与人工标签保持可区分。
6. **归档**：卡片列表与背景统计；空状态回到今晚，删除需二次确认。
7. **设置**：语言、隐私说明、医疗边界、单机数据说明、删除全部数据。

应用启动时若发现未完成录音会显示恢复提示，不把未知状态静默当作完整夜间卡片；本 MVP 通过会话状态字段保留恢复语义，真实系统终止恢复仍需真机长时验证。

## 领域模型与数据所有权

| 模型/服务 | 职责 | 数据所有者 | 生命周期/恢复 |
| --- | --- | --- | --- |
| `NightSession` | 一晚的开始/结束、提示、背景、音频路径、事件、笔记、完成状态 | 应用沙盒 | JSON 索引原子替换；加载时容忍缺失音频并显示不可播放 |
| `SoundMoment` | 时间偏移、峰值、人工标签；不承载自动医学分类 | `NightSession` | 候选只由相对音量与冷却时间产生；用户可忽略或改标 |
| `MomentDetector` | 校准环境基线并生成有界候选 | 内存 | 纯 Dart、可单测；候选数量有上限 |
| `SessionRepository` | 写入、更新、删除单晚/全部，提供音频路径 | 应用支持目录 | 清单采用临时文件后替换；删除优先保障音频消失 |
| `AudioRecorderService` | 权限、录音、振幅、停止/取消 | 系统麦克风 | 隔离插件；失败不创建完成卡片 |
| `ClipPlayerService` | 从候选附近播放短片 | 本地音频 | 页面离开/新播放时停止 |
| `AppController` | 串联状态机、持久化和错误恢复 | 进程内 | 忙碌锁防重复开始/停止；错误可见且可重试 |

## 功能需求与验收标准

| ID | 需求 | 验收标准 | 证据层 |
| --- | --- | --- | --- |
| FR-01 | 准备与同意 | 可输入提示/标签；取消弹层不请求权限、不写会话；再次打开无异常 | Widget + 模拟器 |
| FR-02 | 权限与录音 | 只在确认后请求；拒绝显示设置/重试路径；成功时有持续可见录音标识和停止入口 | Widget + 模拟器；真机待补 |
| FR-03 | 候选生成 | 校准期不生成事件；超阈值且过冷却期才生成；最多 24 个；从不自动标为鼾声/梦话 | 单元测试 |
| FR-04 | 停止与故障 | 停止成功后才创建可复核会话；保存失败显示错误并保留待保存数据，不静默丢失 | 控制器测试 + Widget |
| FR-05 | 晨间核对 | 可播放候选、修改标签、写长笔记、取消编辑不误写、保存后重进保持 | Widget + 模拟器 |
| FR-06 | 删除 | 单晚和全部删除均需确认；取消无变化；确认后索引和应用管理的音频都移除 | 单元/Widget；真机文件待补 |
| FR-07 | 本地化/无障碍 | 中文/英文可切换；关键按钮有语义；不只靠颜色；320pt 小屏和 1.3x 文字下核心操作可达 | Widget + 模拟器 |
| FR-08 | 离线与隐私 | 无网络、账号、分析/广告 SDK；设置内可见本地数据和非医疗说明 | 静态 + 模拟器 |
| FR-09 | 归档回看 | 列表为空/典型/长内容均可达；卡片显示已确认而非自动结论；背景统计来自本地人工数据 | 单元 + Widget + 模拟器 |

## 视觉方向与页面验收

“夜间纸页”使用深靛 `#11152B`、晨光珊瑚 `#FF8E7A`、薄雾 `#F3F1EA` 和月光蓝 `#8CA8FF`。标题克制、留白服务于下一决策；候选时间线用形状+文字表达状态，不用睡眠分数圆环。中文和英文都允许自然换行；归档卡片显示三行预览，点按后的详情页完整呈现用户笔记。

| 页面/状态 | 下一决策与主操作 | 长内容/空间策略 | 验收矩阵 |
| --- | --- | --- | --- |
| 今晚空/已输入 | 是否开始今晚记录；“准备录音” | 单列滚动；键盘出现时按钮可滚动到；长提示最多 160 字并显示计数 | iPhone SE / iPhone 16 Pro / iPad；中英；明暗；大字 |
| 录音说明与拒绝 | 确认权利/隐私或取消；拒绝后重试 | 弹层可滚动，按钮不被安全区覆盖；关闭后可重开 | 小屏；中英；遮罩/返回关闭；重开 |
| 正在倾听 | 确认仍在录音；停止 | 红点+“正在录音”文字；计时和停止始终可见；纵向适配 | 手机；中英；深色；锁屏真机待补 |
| 晨间核对 | 听、标记、写回忆、保存 | 事件列表懒加载/滚动；长笔记多行；键盘不遮保存；空候选仍可保存笔记 | 手机/平板；0/典型/24 事件；大字 |
| 归档/详情 | 打开、回看或删除 | 列表卡显示三行预览并可点按查看全文；详情滚动到底能删除；删除弹层可取消重开 | 中英；空/长内容；明暗；小屏/平板 |
| 设置 | 切换语言、理解数据、删除全部 | 隐私与医疗边界完整可读；危险操作独立区 | 中英；大字；弹层取消/确认 |

## 已知限制

- 候选检测只依据相对音量，不识别声源或内容；房间、设备距离与环境会影响结果。
- 录音文件大小随时长增加；MVP 不做音频切片压缩、存储上限预测或开放导出。
- iOS 锁屏整夜稳定性、音频会话与其他媒体共存、来电/闹钟中断、低存储、热量和耗电必须真机长时验证。
- Android 后台持续录音、系统备份排除、最低 iOS 15 真机、VoiceOver/TalkBack 和签名 Archive 未由自动化测试证明。
