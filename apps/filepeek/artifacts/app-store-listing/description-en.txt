Fylto helps you inspect JSON, CSV, TXT and LOG files on your device. Open a file with the system picker, understand its contents and check a working copy while keeping the original intact.

CHECK AND READ
See format diagnostics for JSON and CSV. Browse CSV rows in a table, search text and logs, and find entries with log-level highlighting. Long content is shown in pages so you can reach the final line.

REPAIR A WORKING COPY
Format JSON, edit a CSV cell or repair a small raw text copy. Recheck the result and undo changes when needed. Fylto does not overwrite your selected source file.

COMPARE JSON
Compare two valid JSON files to review added, removed and changed paths. Inspection reports list difference types and paths without including the compared values.

PREVIEW AND EXPORT
Review an inspection report before sharing it. Export a report or working copy only when you choose to use the system share sheet.

ON YOUR DEVICE
Fylto requires no account and has no advertising, analytics or developer-operated file upload flow. A file provider or sharing destination you select may process files under its own rules. The current inspection session is not restored after the app closes.

Supports UTF-8, including UTF-8 BOM. Files are limited to 5 MiB and 10,000 lines; CSV files support up to 200 columns. Raw copy editing is limited to 128 KiB.
