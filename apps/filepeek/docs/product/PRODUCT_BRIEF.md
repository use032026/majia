# Fylto 产品简报与验收

2026-10-12 初版，2026-10-13 更名为 FileRecheck，并按当前需求移除外部分享导入；范围：Flutter iOS/Android MVP、功能审核、App Store 预检。首发地区中国大陆及英语市场为待确认假设。免费，无账号、服务端、分析或广告。

2026-10-21 仅将产品显示名统一为 Fylto，保留内部标识与现有功能。

## 核心流程

1. 空状态说明支持的 JSON/CSV/TXT/LOG 与文件上限。用户在应用内打开系统文件选择器导入；取消不改变当前会话，读取失败可重试。
2. 显示文件名、大小、编码、类型及解析状态。源文件只读；打开工作副本。无效编码、二进制、过大文件明确报错。
3. 通用不区分大小写搜索。JSON 可格式化、校验并比较另一份 JSON 的结构路径差异；CSV 有带列头的表格、筛选及工作副本的单元格编辑；LOG 按级别着色与搜索；TXT 按行浏览搜索。长内容分页，可跳至末页，不静默截断。
4. 修改只发生在工作副本；可编辑不超过 128 KiB 的原文副本、撤销修改或恢复原件。每次修改后重新诊断。导出处理后副本和简短检查摘要，原文件不覆盖；未导出修改在替换或关闭前提示。检查摘要只列 JSON 差异类型和路径，不写入前后值。
5. 会话存在内存；临时分享文件位于应用缓存。用户可清除当前会话；无应用自有上传。系统文件提供方、系统备份及主动分享的边界需在隐私说明中写清。

## 非目标

大文件流式索引、SSH/URL 导入、后台同步、云盘、账号、协作、复杂 JSON Schema 校验、CSV 公式、语法高亮代码编辑器和自动备份。单文件 5 MiB、最多 10,000 行及 200 列为初版保护阈值；原文副本编辑限 128 KiB；不静默截断或改写。可识别 UTF-8/UTF-8 BOM；其他编码显示错误，不猜测转换。

## 模型与验收

| ID | 验收 |
| --- | --- |
| F1 | 应用内系统文件选择器导入检查会话；取消与异常不丢当前会话；5 MiB 上限可见且生效。 |
| F2 | JSON 合法/错误位置、CSV 引号及行列错误、TXT/LOG 行号与搜索结果正确；空结果明确。 |
| F3 | CSV 单元格修改、JSON 格式化保留原始输入，撤销回原件；变更后诊断立即更新。 |
| F4 | JSON 结构比较含添加/删除/值变化的路径，第二文件出错不会替换当前会话。 |
| F5 | 可主动导出处理副本；检查报告先展示完整预览，返回不导出，点击预览页的导出按钮才触发系统分享；导出失败可重试。 |
| F6 | 中英双语、深浅色、动态文字、小手机和大屏上可读；长文件名换行，表格可水平和垂直滚动，底部操作不被遮挡。 |

## 界面层级

首屏唯一主行动为“打开文件”，展示文件类型和隐私边界。工作台上部固定文件身份与诊断，下面是搜索、按类型显示的处理入口，再下面占主要空间的是内容；导出与清除由清晰的操作区提供。长文件名换行，错误全文可展开；表格保留表头并双轴滚动；多行日志按行号呈现。空、无匹配、解析失败、编辑、比较和导出状态均有明确可返回路径。用低饱和蓝绿、浅色工作纸面与等宽数据文本区分信息层级，深色保持对比；不复刻参考产品。当前不提供从其他应用接收文件分享的入口；主动导出仍使用系统分享界面。

## 运行态验收矩阵

小手机与较大屏、中英、明暗、大字；空页、典型 JSON/CSV/LOG、长文件名与密集表格、错误 JSON、搜索无结果、编辑键盘、比较弹层、导出/取消及滚动末尾。每个状态需记录设备、版本和实测范围；未实测的只列缺口。
