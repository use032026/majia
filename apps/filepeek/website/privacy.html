Privacy Policy

This is a product-specific draft for the current FileRecheck app. The operator has not yet confirmed its legal identity or contact details, so this page is not ready to publish as a live policy.

Information and data

FileRecheck does not require an account. When you select a JSON, CSV, TXT or LOG file with the system picker, the app reads its name and contents to inspect, search and display it. The current inspection session, search terms, diagnostics, comparisons and working-copy edits are held in app memory. The original selected file is not overwritten. The current app source contains no developer-operated file upload, analytics or advertising flow.

Device permissions

File access starts with a file you select through the operating system picker. The current app does not request broad Android all-files access or camera, microphone, location and contacts permissions. Cancelling the picker leaves the current session in place.

Network and third-party services

FileRecheck does not initiate a transfer of selected file contents to a developer-operated server in the current version. A file provider you choose, including a cloud provider, may download or cache the selected file under its own terms. The operating system and any app you choose as a share destination may also process or transmit data independently of FileRecheck.

Storage, retention and deletion

The inspection session is not restored after the app process ends. An onboarding-completion marker remains in the app support directory until app data is removed. Exports made by FileRecheck are written to temporary app cache; the app attempts to delete old app-generated exports on its next launch, and the operating system may clear cache earlier. The system picker or file provider may create its own temporary copies, whose retention FileRecheck does not control. Closing a session removes its in-memory working copy. Uninstalling the app generally removes app-local data, but does not remove original files, cloud-provider copies, system backups or previously shared copies.

Exports and sharing

A working copy or report reaches the system share sheet only after you choose to export it. A report can include the file name, type, size, encoding, line count, diagnostics, and optional search terms or JSON difference paths. It does not include the compared JSON values. Review report contents and the chosen destination before sharing.

Children's privacy

The app does not ask for age or provide child-specific account features. Its file picker can still open content you choose, so a parent or guardian should supervise selection and sharing of any children's information. The final store age rating remains to be confirmed.

Changes to this policy

If FileRecheck's practices change, this page must be updated before the revised version is published. The effective date and a verified public URL will be added after operator review.

Contact

The legal operator and support email are awaiting confirmation. This draft does not provide a live privacy contact.

隐私政策

这是针对当前 FileRecheck 版本的产品草稿。运营主体的法律身份和联系方式尚未确认，因此本页还不能作为正式公开政策发布。

信息与数据

FileRecheck 无需账号。你通过系统文件选择器选取 JSON、CSV、TXT 或 LOG 文件后，应用读取文件名和内容，用于检查、搜索与展示。当前检查会话、搜索词、诊断、比较结果及工作副本修改保存在应用内存中，不覆盖所选原文件。当前源码没有开发者自有文件上传、分析或广告流程。

设备权限

文件访问从你通过操作系统选择器主动选取的文件开始。当前应用不申请 Android 广泛文件访问权限，也不申请相机、麦克风、位置和联系人权限。取消选择不会清除现有会话。

网络与第三方服务

当前版本不会主动把所选文件内容传送至开发者自有服务器。你选择的文件提供方（包括云盘）可能按自己的规则下载或缓存文件。操作系统以及你主动选择的分享目标应用也可能独立处理或传输数据。

存储、保留与删除

应用进程结束后不会恢复检查会话。引导完成标记保存在应用支持目录，直到应用数据被删除。FileRecheck 的导出文件写入应用临时缓存；下次启动时会尝试清除旧导出文件，操作系统也可能提前清理缓存。系统文件选择器或文件提供方可能另建临时副本，其保留期不受 FileRecheck 控制。关闭会话会移除内存中的工作副本。卸载应用通常会删除应用内数据，但不会删除原文件、云盘副本、系统备份或已分享的副本。

导出与共享

只有你主动选择导出，工作副本或报告才会交给系统分享界面。报告可能包含文件名、类型、大小、编码、行数、诊断，以及可选的搜索词或 JSON 差异路径；不会写入被比较 JSON 的前后值。分享前请核对报告内容和目标应用。

儿童隐私

应用不询问年龄，也没有儿童专用账号功能。文件选择器仍可打开你选取的内容；家长或监护人应监督儿童信息的选取与分享。最终商店年龄分级尚待确认。

政策变更

如 FileRecheck 的处理方式改变，应在发布修订版本前更新此页面。生效日期与已验证的公开网址将在运营主体审核后补充。

法律运营主体与支持邮箱尚待确认。此草稿目前不提供正式隐私联络渠道。
