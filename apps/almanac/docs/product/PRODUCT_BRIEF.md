# Almanac 产品简报与 MVP PRD

版本：1.0 · 2026-10-10

## 产品论点

- 目标用户：喜欢传统时间文化意象，但不需要算命、完整月历或长篇阅读的中英文用户。
- 问题：大而全黄历带来信息与信任负担，单句产品又缺少行动和回看。
- 承诺：用约一分钟完成一张不预测吉凶的现代日笺，并把自己的选择留在本机。
- 核心循环：打开今日笺 -> 阅读本机生成的候选与短诗 -> 选一宜一忌 -> 写可选意图 -> 收笺 -> 以践行/调整/放下回看 -> 在笺册留存。
- 耐久输出：版本化 `DailyLeaf` 本地记录与用户主动复制的 Markdown 岁时册。

## 硬约束与非目标

- Flutter；iOS 15+，Android minSdk 24 / targetSdk 36。
- 简体中文和英文；语言切换不改变内容 ID。
- 离线优先、无账号、无应用后台、无广告、无分析、无订阅、无运行时权限。
- 不做真实农历、节气、择日、运势、吉凶评分、天气、日程、诗库、社交或 AI 对话。
- 不使用竞品品牌、文案、截图、数据或交互层级；所有提示与诗句为项目原创。

## 信息架构

1. 首次说明：解释文化灵感、非预测和本地隐私边界。
2. 今日：公历日期、文化标签、每日稳定短诗、三项“宜/Try”和三项“忌/Skip”、可选意图、收笺。
3. 已收笺：展示选择，支持一次或多次重选“践行/调整/放下”的非评判式回看。
4. 笺册：按日期倒序的非月历列表；可打开完整详情。
5. 设置：语言、系统/浅色/深色、复制 Markdown、确认清除、应用内隐私与方法说明。
6. 读取恢复：读取失败时停止写入，提供重试和明确确认后的重置。

## 领域模型与数据所有权

| 模型/服务 | 职责 | 数据所有者 | 生命周期与恢复 |
| --- | --- | --- | --- |
| `PromptItem` | 原创双语提示、宜/忌侧、主题域 | 应用内置内容 | 随版本发布；ID 稳定 |
| `AlmanacGenerator` | 以生成器版本、安装种子、本地日期确定性抽取提示和成句 | 应用 | 365 天约束测试；无网络随机数 |
| `DailyLeaf` | 冻结日期、生成内容、用户选择、意图和回看 | 用户 | 首次生成即写入；历史不随内容包改变 |
| `AlmanacData` | 安装种子、语言/外观、全部日笺 | 用户 | JSON schema v1；读取异常锁定写入 |
| `StateStore` | 保存完整状态 | 用户设备 | 写入成功后才提交内存状态；失败保留旧内存/旧磁盘 |

## 生成规则

- 种子：`hash(generatorVersion | installationSeed | localDate)`。
- 宜、忌各取三项，保证当日不重复并覆盖三个不同主题域。
- 诗句主题来自当日第一项宜；中英文是人工编写的对应表达，不冒充古诗或历史翻译。
- 同一安装、同一日期、同一版本结果固定；重启和语言切换不改变。
- 首版避免季节、天象、节气、方位等依赖地域或历法准确性的事实陈述。

## 失败与恢复

- 读取或解析失败：不创建空状态、不继续写；重试或明确重置。
- 写入失败：不更新内存状态，保留上一份存储值，显示可重试错误。
- 空意图合法；上限 140 字符。
- 反射弹层取消不写数据，再次打开不抛异常。
- 清除日笺需二次确认；保留语言、外观和安装种子，重新生成未收笺的今日内容。
- 用户主动复制 Markdown 会把内容交给系统剪贴板；应用内说明这一边界。

## 功能验收标准

| ID | 需求 | 验收标准 | 证据层 |
| --- | --- | --- | --- |
| FR-01 | 离线今日内容 | 无网络/账号/权限可生成；同日重启一致；365 日期无重复候选或空句 | 单元测试 + 运行态 |
| FR-02 | 双语一致 | 切换语言只改变文案，不改变提示 ID、诗句选择或用户数据 | 控制器 + Widget |
| FR-03 | 收笺 | 必须选择一宜一忌；可选 140 字意图；成功后重启仍存在 | 控制器 + Widget + 运行态 |
| FR-04 | 数据安全 | 保存失败不得显示成功或覆盖旧状态；损坏读取进入锁定恢复 | 单元测试 + Widget |
| FR-05 | 回看与弹层 | 可选择三种非评判结果；取消、关闭动画和重开无异常、无误写 | Widget + 运行态 |
| FR-06 | 笺册与复制 | 已收笺按日期倒序；详情完整；复制包含全部记录和边界说明 | Widget + 手工检查 |
| FR-07 | 删除 | 二次确认；删除应用管理的记录；设置保留 | 控制器 + Widget |
| FR-08 | 可达性 | 不仅靠红绿传达；语义含选中状态；核心控件可滚动到达；200% 文字无框架异常 | Widget + 模拟器 |

## 视觉方向与验收矩阵

现代日笺使用暖纸色、墨色、矿物绿和朱砂印记；首页是一条连续阅读流，不使用传统月历表格、书架、章节或翻页。核心信息完整换行，不用省略号隐藏。

运行态至少检查：紧凑 iPhone、较大 iPhone、iPad；Android 360×640 与较大手机；中英文；浅/深色；100%/200% 文字；首次、草稿、已收笺、已回看、空笺册、长内容、存储错误；键盘、弹层关闭/重开、滚动末端和底部安全区。

## 已知限制

- SharedPreferences 适合小规模文本记录，但不是大容量数据库；规模增长后需版本化迁移到文件或数据库。
- 当前没有应用级备份文件；Markdown 复制是可读导出，不是无损恢复格式。
- 不提供真实农历/节气，因此不能以完整黄历宣传。
- 真机、签名 Archive、最终 AAB/IPA、公开 URL 和商店元数据属于后续证据层。
