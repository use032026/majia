# 微成 · Steady21 产品简报与 MVP PRD

版本：2026-09-22 / approved implementation candidate
范围：Flutter iOS/Android MVP + 功能审核 + iOS App Store 本地预检；不上传、不提交。

## 产品论点

- 目标用户：想开始一个具体日常行动、但容易因低精力或一次中断而放弃的中文或英文个人用户。
- 昂贵问题：普通连续打卡只回答“断没断”，不能帮助用户缩小动作、识别阻碍或决定下一周期怎么改。
- 产品承诺：把愿望变成带触发线索的标准/最低行动，记录每日结果与阻碍，在中断后选择恢复策略，并于阶段节点留下个人实验结论。
- 核心闭环：定义实验 -> 当日行动/观察 -> 中断恢复 -> 7/14/21 天复盘 -> 本地实验报告 -> 继续或归档。
- 耐久输出：逐日记录、累计练习、恢复次数、常见阻碍、称号、阶段决定和下一周期计划。
- 科学边界：21 天是启动周期和里程碑，不承诺固定天数必然形成自动化习惯。

## 非目标

- 不做多个同时进行的实验；一次只聚焦一个微行动，归档后再开始下一项。
- 不做社区、排行榜、社交监督、账号、云同步、广告、订阅、AI 教练、情绪/饮水/健康数据。
- 不做通知、桌面小组件、图片打卡、补签或未来日期；这些不是证明本闭环所必需。
- 不复制参考产品的品牌、严格清零叙事、热力图、页面顺序、截图、图标或商店文案。

## 规则与领域模型

| 模型/服务 | 职责 | 生命周期与恢复 |
| --- | --- | --- |
| `Experiment` | 标题、触发线索、标准行动、最低行动、目标练习天数、开始时间、归档状态 | 同时最多一个 active；归档保留报告；可删除 |
| `DailyEntry` | 本地日历日、结果（完整/最低/跳过）、阻碍、恢复策略、备注 | 每个实验每天至多一条；只允许新建/改正/撤销今天；跳过必须选择阻碍和下一次策略 |
| `MilestoneReview` | 7/14/21 完成日的决定（保持/减量/换时间/换线索/结束）及备注 | 达到累计练习阈值后出现；每阈值一条，可修改 |
| `ExperimentStats` | 累计练习、标准/最低次数、跳过、当前/最佳连续、恢复次数、常见阻碍、称号 | 由源记录纯函数计算；不得单独持久化为真相 |
| `AppSnapshot` | 当前实验、归档实验、语言、模式版本 | JSON schema v1；未知/损坏数据加载失败且不覆写原文件 |
| `LocalRepository` | 读取与原子保存 | 先写临时文件再替换；保存成功后控制器才提交内存状态 |

### 称号阈值

按累计练习日（完整或最低均算练习）计算：0 起念时刻；1–6 小试牛刀；7–14 渐入佳境；15–20 稳步推进；21 廿一新章；22–30 稳步成章；31+ 长期同行。英文对应 Spark、First Steps、Finding Rhythm、Building Momentum、Twenty-One Turn、Steady Chapter、Long Haul。

## 信息架构与状态

1. `载入/恢复`：启动读取本地文件；无数据进入空状态；损坏或读取失败显示可重试错误，不覆写。
2. `今日`：首屏回答“今天做标准行动、最低行动还是暂停观察”；展示触发线索、当前称号和目标进度。
3. `创建/编辑实验`：标题、触发线索、标准行动、最低行动、目标练习天数（1–365，默认 21）；取消不写入。
4. `今日记录 Sheet`：选择完整/最低/跳过；跳过时阻碍和恢复策略必填；关闭/取消不写入；保存失败保留旧状态并可重试。
5. `历程`：阶段路径、累计统计、常见阻碍、逐日记录和阶段复盘；长内容完整换行并可滚动到尾部。
6. `阶段复盘 Sheet`：达到 7/14/21 日时记录下一决定；关闭/取消不写入；可重开修改。
7. `报告/归档`：达到目标后显示报告摘要；可继续延展或归档；归档后仍可回看并可开始新实验。
8. `设置/隐私`：中英文切换、本地数据边界、全部删除确认；无账号/支付入口。

## 功能需求与验收标准

| ID | 需求 | 验收标准 | 证据层 |
| --- | --- | --- | --- |
| FR-01 | 创建和编辑实验 | 必填字段拒绝纯空白；目标限制 1–365；取消/返回/失败不新增；active 存在时不能静默创建第二个 | 单元 + Widget + 运行态 |
| FR-02 | 今日记录 | 同日最多一条并可改正；完整/最低计入累计，跳过不计；跳过必须选择阻碍和恢复策略；撤销有确认 | 单元 + Widget + 运行态 |
| FR-03 | 统计与称号 | 所有阈值 0/1/6/7/14/15/20/21/22/30/31 正确；连续记录按当地日历日；修改/撤销后重算 | 单元测试 |
| FR-04 | 温和恢复 | 跳过不清除历史；报告可见阻碍、恢复次数和策略；下一次仍可继续同一实验 | 单元 + Widget + 运行态 |
| FR-05 | 阶段复盘 | 累计练习达到 7/14/21 后出现待复盘；保存决定并可修改；取消无写入 | 单元 + Widget + 运行态 |
| FR-06 | 报告与归档 | 报告显示完成方式、常见阻碍、恢复次数、阶段决定；达到目标可归档或继续；归档不丢数据 | 单元 + 运行态 |
| FR-07 | 持久化与恢复 | JSON 往返一致；写入失败不提交内存状态；损坏 JSON 不覆盖原文件；重启恢复语言和实验 | 单元 + 模拟器重启；真机待补 |
| FR-08 | 删除与隐私 | 删除实验/全部数据需确认；取消不变；应用内明确本地、备份、卸载、无同步边界 | Widget + 运行态 |
| FR-09 | 本地化/无障碍 | 无裸露内部 key；中英长文本可到达；控件语义清晰；系统深浅色、动态文字、手机/平板可用 | Widget + 模拟器矩阵；读屏真机待补 |
| FR-10 | 离线 | 核心闭环无网络依赖、无账号、无分析/广告 SDK；飞行模式不改变功能设计 | 静态依赖审计 + 运行态；真机飞行模式待补 |

## 页面与视觉验收

视觉方向：原创纸张式实验日志。暖米白/近黑为底，深墨绿代表行动，陶土色代表需要调整；不使用竞品截图或品牌。主界面不以热力图为中心，而以“触发线索 -> 今日二选一行动 -> 观察/恢复”层级展开。

| 页面/状态 | 用户决定 | 必须可见或可到达 | 压力策略 | 验收矩阵 |
| --- | --- | --- | --- | --- |
| 今日空/有数据 | 开始实验或记录今天 | 主标题、触发线索、标准/最低行动、记录入口、保存错误 | 长标题/行动换行；卡片整体滚动；底部安全区不遮挡 | 紧凑 iPhone 中英/大字/深色；iPad 英文 |
| 创建/记录 Sheet | 填写或取消 | 所有字段、键盘关闭、取消/保存、跳过条件项 | 键盘 inset + 滚动；返回/遮罩关闭后可重开 | iPhone 中英；关闭动画后重开 |
| 历程/报告 | 决定继续、调整或归档 | 称号、阶段、统计、阻碍、逐日记录、复盘与尾部操作 | 不以省略号隐藏关键值；长列表可达尾部 | 紧凑 iPhone 30+ 条；iPad；深色/大字 |
| 设置/删除 | 切换语言或删除 | 隐私边界、删除确认、取消 | 对话框可返回/重开；破坏操作区分 | 中英/深色/大字 |

## 已知限制

- 工作名、Bundle ID、图标、隐私/支持 URL、ASC 元数据和最终商店截图尚未定稿。
- 只允许今天记录/改正，避免把补签和时区迁移引入 MVP；跨时区和系统时间倒退需作为未验证层报告。
- 无导出/独立备份；系统备份行为取决于用户设备和平台设置。
- 通知、Widget、分享、账号同步、健康数据和平台权限均不在本轮。
- 模拟器不能代替实体设备、签名 Release、上传、TestFlight 或 App Review。
