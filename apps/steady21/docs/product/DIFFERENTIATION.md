# 微成 · Steady21 差异化与原创性报告

评审日期：2026-09-22

## 结论

`passed`，但只批准“21 天行为实验册”修订方向。原始“21 天 + 打卡 + 称号”概念为 `needs_revision`：参考产品已覆盖自定义天数、打卡、统计、归档、提醒和成就，差异主要停留在天数与文案。

批准实现的产品论点：为容易开始、也容易中断的个人用户提供一个完全离线的微行动实验；用户定义触发线索和标准/最低行动，每天记录结果与阻碍，在中断后选择恢复策略，并在 7/14/21 天留下可复用结论。

## 硬失败扫描

- 不只改名称、图标、颜色、文案、语言、地区或 Bundle ID：`通过`；差异进入数据模型和阶段决策。
- 不复刻竞品屏幕层级和主操作：`通过`；采用“今日实验 -> 恢复卡 -> 阶段复盘 -> 实验报告”结构，不以热力图为中心。
- 不使用竞品截图、品牌、素材、数据集或文案：`通过`；参考页只作市场证据。
- 不是同模板低差异版本：`通过`；工作区原有内容为静态概念目录，本工程独立创建。
- 无装饰性登录、订阅、广告、社区或 AI：`通过`；均不实现。
- 无规避历史拒审或隐藏关系意图：`通过`；未发现相关输入。

## 称号边界

用户给出的 `1–7` 与 `7–14` 在第 7 天重叠，工程按半开区间消歧，并在界面显示无重叠范围：

- 0 天：起念时刻 / Spark
- 1–6 天：小试牛刀 / First Steps
- 7–14 天：渐入佳境 / Finding Rhythm
- 15–20 天：稳步推进 / Building Momentum
- 第 21 天：廿一新章 / Twenty-One Turn
- 22–30 天：稳步成章 / Steady Chapter
- 31 天以上：长期同行 / Long Haul

称号是辅助反馈，不使用羞辱性失败标签，也不代表习惯已经自动形成。

## 竞品无关的产品理由

即使没有参考产品，用户也需要把模糊愿望转换为可执行的触发-行动计划，并在低精力日保留最低行动。一次中断带来的信息如果只被“连续天数清零”覆盖，就无法回答下一次应缩小行动、换时间、换线索还是停止。因此应用的耐久价值是个人实验结论，而不是徽章数量。

## 防止产品漂移的边界

- 不实现社交排行、公开社区、账号、云同步、广告、订阅或 AI 教练。
- 不复制参考产品的 Project 50 品牌、严格重启叙事、热力图造型、截图、文案或页面顺序。
- 不宣称 21 天必然养成习惯；只称启动周期、练习里程碑或行为实验。
- 后续扩展必须增强“定义 -> 行动 -> 观察 -> 恢复 -> 复盘 -> 报告”闭环，并保持本地删除和错误恢复能力。
