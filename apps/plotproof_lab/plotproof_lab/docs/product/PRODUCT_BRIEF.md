# PlotProof Lab（图证实验室）产品简报与 MVP PRD

生成时间：2026-09-09T00:00:00+08:00

## 产品论点

- 目标用户：需要把统计规则迁移到真实读图场景的学生与普通读者。
- 昂贵问题：被视觉尺度、样本遗漏、异常点和表述框架影响，却不知道结论是如何被放大的。
- 产品承诺：每个实验只改变一个关键变量，并用同数据对照解释结论边界。
- 核心闭环：先判断 → 操作 → 修复 → 解释 → 记录 → 复练。
- 耐久输出：不会离开设备的个人误区和掌握进度。

## 非目标

- 不提供新闻聚合、浏览器、事实核查结论、实时数据或外部链接目录。
- 不导入用户文件、不分享或同步学习数据；这些能力需单独做隐私与失败恢复设计。
- 不复制参考 App 的文案、题目、导航、图标、截图或品牌表现。
- 不把“所有非零轴都错误”等启发式包装成绝对规则；解释必须包含图表类型和语境。

## 信息架构与状态

1. “学习”首页：继续练习、总体完成度、四类实验入口和离线优先声明。
2. 模块页：显示关卡、完成/错题状态及学习目标。
3. 实验页：情境与初始图 → 必须先提交判断 → 解锁参数 → 公平对照与解释 → 完成。
4. “复练”页：按最近错误列出关卡，可重新进入；没有错误时显示可解释空状态。
5. “进度”页：完成关卡、正确率、误区分布及最近记录。
6. “设置”页：中英文切换、题库更新、离线/隐私说明、确认后清除全部学习记录。

八个随包实验不需要网络加载或系统权限。应用至多每七天通过 HTTPS 检查一次版本化题目包，总题库上限为 56 题：八个随包实验固定保留，动态题最多 48 题；达到上限后每新增几题，就按首次加入顺序移除最早的几道动态题，同 ID 更新不视为新增。校验失败继续使用随包内容和上一次有效缓存；不上传作答或语言偏好。持久化失败时不得把完成状态留在内存中冒充已保存；删除必须二次确认；复练与普通进入共享同一可取消路径。

## 领域模型与数据所有权

| 模型/服务 | 职责 | 数据所有者 | 生命周期与恢复 |
| --- | --- | --- | --- |
| `Lesson` | 双语情境、合成或有来源公开数据、正确判断、实验模式与误区标签 | 应用只读内容 | 八题随版本发布；动态题按周版本化并校验来源/许可/哈希 |
| `LessonCatalogRepository` | 加载缓存、按周期下载并校验动态题目包 | GitHub Raw 上的只读 JSON；设备本地缓存 | 最多保留 48 道动态题并按首次加入顺序淘汰；下载失败保留上次有效内容；不发送学习记录 |
| `Attempt` | 初始判断、是否正确、完成时间、误区标签 | 用户本机 | 完成解释后原子保存；可复练、可全部删除 |
| `ProgressRepository` | 加载、保存、清除尝试与语言偏好 | 用户本机 | SharedPreferences；解析失败回退空集合并暴露错误 |
| `ExperimentMath` | 坐标轴放大率、相关系数、抽样估计和风险换算 | 无持久数据 | 纯 Dart、确定性、可单元测试 |

## 功能需求与验收标准

| ID | 需求 | 验收标准 | 证据层 |
| --- | --- | --- | --- |
| FR-01 | 可发现并进入四类、至少八个离线实验 | 首屏可达；随包关卡在飞行模式仍完整；完成状态可见 | Widget + 模拟器 |
| FR-02 | 先判断后实验 | 调参控件在判断前锁定；提交后可观察参数变化和同数据公平对照 | 单元 + Widget + 模拟器 |
| FR-03 | 解释与结果可信 | 每关提供结论边界、检查清单和自创数据说明；正确性不受“只调控件”作弊 | 单元 + 源码审核 |
| FR-04 | 持久化与复练 | 完成后保存；重启恢复；错误进入复练；重新正确作答后不再属于未掌握；删除需确认 | 单元 + Widget + 模拟器 |
| FR-05 | 中英文/无障碍/响应式 | 所有核心文案双语；遵循系统明暗；大字不遮挡主操作；图表有语义摘要；手机和平板可操作 | Widget + 模拟器；读屏真机待补 |
| FR-06 | 隐私和离线边界 | 无登录、系统权限、广告或分析 SDK；仅匿名获取题目包且不上传本地记录；设置页可查看说明并清除记录 | 依赖审计 + 静态 + 网络行为 + 模拟器 |
| FR-07 | 题库更新、上限与失败回退 | 每七天最多自动检查一次；仅接受 HTTPS、受支持 schema、唯一远程 ID、合法实验参数和 SHA-256 一致的题目包；总题库不超过 56，同 ID 原位更新，新增超限时等量淘汰最早动态题；失败继续使用现有题库 | 单元 + Widget + 网络夹具 |

## 视觉方向

原创“证据工作台”：深墨蓝信息底、暖琥珀实验变量、薄荷绿公平对照。顶部说明正在检验的论断，中部图表与参数控件组成实验台，下部把“发现—修复—检查规则”逐步展开。颜色不是唯一状态编码；完成、错误和锁定同时使用图标、文字和语义。布局以 Material 3 组件为基础但不模仿参考产品。

## 已知限制

- 全部案例是合成教育数据，不能判定现实新闻真伪，也不是统计、医疗或投资建议。
- MVP 不含教师端、导入、分享、云同步或内容更新后台。
- 实体设备、VoiceOver/TalkBack、签名 Archive、公开 URL 与 App Store 元数据必须在后续证据层补齐。
