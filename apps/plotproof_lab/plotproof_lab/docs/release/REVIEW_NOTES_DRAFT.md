# PlotProof Lab（图证实验室）App Review Notes Draft

Status: local draft. 提交前必须对照准确的生产 Bundle ID、签名构建和 App Store Connect 记录复核并删除内部备注。

## 核心用途

PlotProof Lab 是一个离线优先的数据识读训练工具。用户不是简单回答真假题，而是先提交判断，再操作坐标轴、异常点/混杂因素、样本构成或概率表达，比较同一数据的两种呈现，阅读结论边界，并按本地错误记录复练。

八个随包案例为原创合成教学内容。应用还可定期读取由 Our World in Data 与 World Bank 白名单公开指标生成、带来源和许可说明的坐标轴/相关性实验。应用不抓取或判断实时新闻，不提供投资、医疗、统计或事实核查建议。

## 审核路径

1. 启动后无需登录、网络、演示账号或特殊配置；“学习”页直接显示四类八个随包实验。联网时可在后台或“设置 → 题库更新”获取动态实验。
2. 打开任一关卡，先选择“有误导性 / 表达公平 / 证据不足”之一；提交前实验控件保持锁定。
3. 提交后改变一次实验参数，再点“查看对照与解析”。页面会显示初始与对照表达、判断结果、解释和检查清单。
4. 故意选错一次后返回底部“复练”；最近错误关卡会进入队列。用正确答案重做后，该关卡会从复练队列移除。
5. “进度”显示本地作答次数、正确率和误区；“设置”可切换简体中文/English，并通过二次确认清除全部学习记录。

## 账号、网络与数据

- 账号：无，且所有核心功能免登录。
- 后端：无应用自有后端；核心流程可离线运行；应用至多每七天匿名读取一次公开 GitHub Raw JSON 题目包。
- 远程内容：只读题目包必须通过 schema、HTTPS 来源、实验参数和 SHA-256 校验；失败时继续使用随包内容和上一次有效缓存。
- 本地数据：SharedPreferences 仅保存学习尝试和语言偏好。
- 删除：设置页“清除全部学习记录”二次确认后删除本机作答。
- 演示凭据：N/A。
