# ReaderEdit 产品简报与 MVP PRD

更新日期：2026-09-30
范围：Flutter MVP、功能审核与 App Store 本地预检；不上传、不提交。

## Intake

| 项目 | 决定或假设 |
| --- | --- |
| Flutter 工程名 | `reader_edit` |
| 目标用户 | 需要在手机或平板上离线创建、导入、阅读和反复修订小说章节的中英文独立写作者 |
| 高频问题 | 长篇正文不适合反复复制到临时表单；作者需要整本书与章节结构、阅读时立即修改，以及精修时可回溯的读者反馈 |
| 产品承诺 | 把本地小说书架、章节阅读编辑和结构化读者视角修订放在同一个无账号工作区 |
| 核心闭环 | 创建小说或导入 TXT/Markdown → 章节阅读 → 原位切换编辑并保存 → 对合适章节发起读者通读 → 信号队列 → 前后对照与核对 |
| 平台 | Flutter；iOS 15+、Android 7.0/API 24+；本轮单独评估 iOS App Store |
| 语言 | 简体中文、英语；用户可在应用内切换 |
| 变现 | 免费、无 IAP |
| 账号/后台 | 无账号、无应用后台、无同步、无广告或分析 |
| 数据 | 小说、章节和修订记录保存在应用支持目录的本地 JSON；原子替换并保留上一版恢复副本；语言/外观在本地偏好中 |
| 文件输入 | 系统文件选择器；TXT、MD、Markdown；UTF-8 或带 BOM 的 UTF-16；最多 8 MiB 原始文件、200 万字符、1000 个识别章节 |
| 权限 | 不申请运行时权限；文件访问由系统选择器授予单次选取范围 |
| 输出 | 用户明确操作时把修订稿或修订记录复制到系统剪贴板 |
| 禁止动作 | 不创建/修改生产证书或账号；不上传 App Store Connect；不提交审核 |

## 非目标

- 不提供平台发布、内容社区、多人协作、收入和作品运营。
- 不提供账号、云同步、订阅、广告、推送和分析。
- 不提供 AI 续写、自动改稿、敏感内容审核或质量分数。
- MVP 不提供富文本、图片章节、EPUB/DOCX/PDF 导入、Files 导出或跨设备备份。
- 不复制参考产品的图标、商店文案、截图、导航、品牌色或布局。

## 信息架构与核心状态

1. 首页/书架：显示本地小说；可创建空白小说或导入长文本；下方保留读者视角修订记录。
2. 小说详情：显示章节数、字符数和简介；可新建章节、把文本导入现有小说、打开或删除章节。
3. 章节阅读：完整显示正文、字符数和本地边界；可随时切换编辑。
4. 章节编辑：同页编辑标题与最长 200 万字符正文；保存后回到阅读；未保存退出需确认。
5. 文件导入：按常见“第…章/节/回/卷/篇/部”与 Markdown `#` 标题切章；无标题时作为一个可编辑章节；导入整本或追加到现有小说。
6. 建立读者视角：章节可预填到现有流程，也允许单独输入；逐段精修仍限制 2–80 段、30,000 字符。
7. 读者通读与修订队列：冻结原稿、记录清楚/拖沓/迷失信号、前后对照修改、承诺复核与复制输出。
8. 设置与恢复：双语、深色、隐私说明、清空全部；主文件异常时读取上一版并明确提示。

错误/恢复状态包括：空文件、错误编码、超出大小/章节数、保存失败不提交、未保存离开确认、删除确认、旧 schema 迁移、主/备份恢复、逐段修订边界提示和剪贴板失败。

## 领域模型与数据所有权

| 模型/服务 | 职责 | 生命周期与恢复 |
| --- | --- | --- |
| `Novel` | 本地书籍标题、简介、章节集合、创建/更新时间 | 创建到用户删除或卸载；随工作区快照保存 |
| `NovelChapter` | 稳定 ID、章节标题、可编辑长正文、创建/更新时间 | 可直接读写；单章最多 200 万字符 |
| `NovelImportPlan` | 文件名转书名、换行归一化、章节标题识别、导入边界校验 | 只存在于导入事务中；失败不写入 |
| `RevisionSession` / `PassageRevision` | 读者承诺、冻结原稿、稳定段落、信号、备注、修订和完成状态 | 逐段精修流程；保持原有 30,000 字符/80 段上限 |
| `ReaderEditStore` | 先持久化后替换可见状态；小说、章节、导入与修订状态转换 | 保存失败时 UI 保持旧状态 |
| `JsonFileSessionRepository` | schema v2 工作区、原子临时写入、主文件、上一版恢复副本 | 可读取 schema v1 修订数据并迁移；删除提交不会被旧备份复活 |
| `FileSelectorTextImportService` | 调用系统文件选择器并严格解码 UTF-8/UTF-16 | 不保留外部文件句柄；正文复制进本地工作区 |
| 系统剪贴板 | 明确导出的修订稿或修订记录 | 点击后离开 ReaderEdit 控制边界 |

## 功能需求与验收标准

| ID | 需求 | 验收标准 | 证据层 |
| --- | --- | --- | --- |
| FR-01 | 创建小说 | 名称必填；简介可选；成功后进入小说详情；失败不产生半成品 | Store + Widget + 模拟器 |
| FR-02 | 创建与删除章节 | 新章节进入编辑模式；章节标题必填；删除需确认且恢复文件不复活正文 | Store + Widget；恢复文件单测 |
| FR-03 | 导入小说/章节 | TXT/Markdown 由系统选择；UTF-8/UTF-16；常见标题自动切章；无标题单章；取消不写数据 | Domain + Store + Widget；真实 Files 选择待真机 |
| FR-04 | 阅读时编辑 | 章节阅读页完整显示正文；一键切换编辑；保存后立即回到阅读且重启仍存在；脏数据退出确认 | Widget + iOS 模拟器 |
| FR-05 | 长文本边界 | 原始文件 ≤8 MiB、正文 ≤200 万字符、≤1000 章；错误编码/空文件显示失败，不覆盖现有小说 | Domain + Widget |
| FR-06 | 建立修订会话 | 标题、原稿、三项承诺必填；2–80 段、≤30,000 字符；章节可预填 | 单元 + Widget |
| FR-07 | 读者通读 | 每段必须选择信号；原稿和稳定段落 ID 不变；未保存离开确认 | Store + Widget |
| FR-08 | 信号队列/前后对照 | 仅拖沓/迷失进入；修订不能为空；无改动不得直接解决；可重开和重判 | 单元 + Widget |
| FR-09 | 承诺复核与输出 | 通读完成、无未解决信号、三项承诺复核后完成；复制正文/记录边界明确 | 单元 + Widget；真机剪贴板待补 |
| FR-10 | 持久化与迁移 | schema v1 无损读入；schema v2 同存小说与修订；原子替换/备份恢复；失败不改变 UI | 文件单元 + Store |
| FR-11 | 删除与隐私 | 小说、章节、修订、全部清空有对应确认；无账号/后台/分析/广告 | Widget + 静态 + Archive |
| FR-12 | 中英文与适配 | 核心文案双语；支持深色、大字、小屏和 iPad 宽度 | Widget + 模拟器 |

## 视觉方向与页面层级

视觉仍是原创“编辑批注台”：暖纸底、深墨正文、蓝紫主路径、珊瑚有限警示。书架用简化书封和章节序号建立层级；章节正文保持大行距和长阅读宽度，编辑入口始终位于右上角。首屏第一决策变为“创建/导入小说”，读者视角修订作为同一产品中的精修工具，而非唯一入口。

| 页面/状态 | 必须可见或可到达 | 长内容策略 |
| --- | --- | --- |
| 首页书架 | 创建、导入、本地边界、小说卡、修订记录、设置 | 全页滚动；操作 Wrap；小说和修订分区 |
| 小说详情 | 统计、新建/导入、章节顺序、删除 | 章节列表滚动；长标题省略但详情完整 |
| 章节阅读 | 标题、字符数、完整正文、编辑、读者修订 | 正文自然滚动，不截断 |
| 章节编辑 | 标题、正文、保存、未保存退出确认 | 多行编辑区自然增长；键盘可收起 |
| 导入错误 | 编码/大小提示，不产生数据 | SnackBar；现有内容保持不变 |
| 原有修订流程 | 通读、队列、对照、核对、输出 | 沿用已验收响应式策略 |

## 已知限制

- 自动切章是保守规则，不解析复杂排版；错误识别后用户可在章节编辑器中修正，但 MVP 尚无合并、拆分、重排和批量重命名。
- 仅支持纯文本/Markdown；不保留字体、图片、脚注或富文本格式；不支持 GBK/GB18030、EPUB、DOCX、PDF。
- 阅读页按单章渲染完整正文；200 万字符是保护上限，不等于所有低内存设备都能流畅编辑极限文件。
- 逐段读者修订仍适合 30,000 字符以内的章节；更长章节可直接编辑，但需要先拆章才能使用逐段信号工作流。
- 只提供剪贴板修订输出，没有 Files/分享面板和应用外备份；卸载可能删除应用沙盒数据。
- 本轮不证明实体设备、真实 Files 导入、VoiceOver/TalkBack、最低 iOS 15、低存储中断、签名分发、App Store Connect 或 App Review。
