ASTFX is a table quality workbench for CSV, TSV, TXT, and XLSX files. Inspect common data problems on your device, decide each change, and export a working copy with a concise quality report.

CONFIRM BEFORE INSPECTION
Open a file through the system picker. Confirm the detected text format and UTF-8 or GBK encoding, or choose an Excel worksheet, before starting the inspection.

REVIEW FIVE COMMON PROBLEMS
Find missing values, normalized duplicate rows, stray spaces, mixed numeric column types, and inconsistent or invalid dates. A repair queue shows the affected row, column, current value, and available suggestion.

KEEP CONTROL OF EACH CHANGE
Apply a suggestion, enter a replacement, remove a duplicate row, or keep a value as-is. ASTFX checks the table again after each decision. Undo is available for decisions made during the current session.

PREVIEW THE RESULT
Review the first five rows in a compact table, scroll across columns, and tap a cell to read its full value. A chart of the first available numeric column helps you check the working copy.

EXPORT DATA WITH CONTEXT
Share a CSV and a Markdown quality report through the system share sheet. When unresolved issues remain, the CSV is named as a draft and the report includes the unresolved count. The report summarizes file details, quality scores, and decisions without embedding complete source rows.

LOCAL WORK, ORIGINAL FILE PRESERVED
Parsing, inspection, repairs, previews, and report creation run on your device. No account is required. The app does not include advertising, developer-operated analytics, cloud sync, or an app-operated backend. One project, its source snapshot, working copy, audit actions, and a local recovery backup are saved in app-private storage. Your selected source file is never overwritten. You can remove the saved project from the app.

Files chosen from cloud file providers, operating-system backups, and export destinations may be handled by those services under their own rules. ASTFX attempts to remove temporary export files after sharing and retries leftover cleanup at the next launch or export.

English and Simplified Chinese interfaces and reports are available, with system light and dark appearance. A built-in sample demonstrates the inspection workflow.

Supported input limits: 5 MB per file, 10,000 data rows, 100 columns, 100,000 cells, and 500 detected issues. ASTFX is a focused inspection and repair tool, not a full spreadsheet editor.
