Privacy Policy

This draft describes the current ASTFX 1.0.0 app and its static product website. The legal operator and policy effective date must be confirmed before publication. Support and privacy contact shown in the existing project: 15211857631@163.com. This is a product-specific draft and has not received legal review.

Information and data

ASTFX reads a table only after you choose it in the system file picker. Parsing, quality checks, repair decisions, previews, and report creation take place on the device. The saved project includes the selected file name, source snapshot, working copy, detected issues, and audit actions. Language and onboarding completion are saved locally. The app has no account registration, developer-operated backend, cloud sync, advertising SDK, analytics SDK, tracking SDK, or online AI service. Its code does not send table content or usage events to the developer. A file you choose can itself contain personal or confidential information; choose imports and sharing destinations with care.

Device permissions

The core app uses the system file picker, app-private storage, and the system share sheet. Its release manifests do not declare camera, photos, microphone, location, contacts, notification, or cross-app tracking permissions. There is no request for broad access to all files. Android development builds include the INTERNET permission for Flutter debugging; that declaration is in debug/profile configuration, not the main app manifest.

Network and third-party services

The app has no application-operated network service. A selected file provider may retrieve a file from its own cloud service before providing it to ASTFX. Operating-system backup, migration, store distribution, and diagnostic services may process app-related information independently under their own settings and policies. This website includes no analytics, advertising, remote fonts, or third-party scripts. It stores only a language choice in browser localStorage. A deployed host may process IP addresses and request metadata to deliver pages; the final host, production domain, and hosting log settings remain to be confirmed before publication. If you choose to email support, your email provider and the recipient process what you send; avoid including sensitive table contents.

Storage, retention, and deletion

One project is kept in the app-private documents directory until replaced by another project, removed through the app, or removed by the operating system when the app is uninstalled. Saving uses a temporary file and a backup of the previous valid project for local recovery. Removing a project also removes its temporary save and local backup. Preferences remain until app data is removed. Operating-system device or cloud backups can retain their own copies according to your settings; a local recovery backup is not a developer cloud service. The original file selected from the file provider is never overwritten or deleted by ASTFX.

Exports and sharing

Only after you request an export does ASTFX create CSV and Markdown files in its dedicated temporary export directory and offer them through the system share sheet. The report includes file details, counts, quality scores, and action summaries rather than complete source rows. When unresolved issues remain, the CSV is labeled draft. You choose the destination; that destination controls its own copy and processing. A share-sheet completion result does not prove that a particular external service stored the files. The app attempts to delete staged files when sharing returns and retries leftover cleanup at the next launch or export. Copies saved or sent elsewhere are not removed when you delete the local project.

Children's privacy

The app does not request an age, date of birth, child profile, or account. If a child uses the app, a parent or guardian should consider the personal information in selected files and supervise sharing. The intended store audience and age rating must be confirmed separately before release. Questions about information voluntarily sent to support can be directed to the contact below.

Changes to this policy

This policy should be updated when the implementation or data handling changes. The published version must state an effective date and identify the operator. Review the current policy before importing or sharing sensitive files. Questions and local-data requests can be sent to the support contact; the developer cannot access a project that exists only in your device storage.

隐私政策

本草稿说明 ASTFX 1.0.0 当前应用及静态官网的数据处理方式。正式发布前须确认运营主体和政策生效日期。现有项目中的支持与隐私联系邮箱为 15211857631@163.com。这是一份针对当前产品实现的草稿，尚未经法律审核。

信息与数据

只有你在系统文件选择器中选中文件后，ASTFX 才读取该表格。解析、质量检查、修复决定、预览和报告生成均在设备上完成。本地项目包含文件名、源数据快照、工作副本、问题和审计动作。语言和引导完成状态也保存在本机。当前应用没有账号注册、开发者后端、云同步、广告 SDK、分析 SDK、追踪 SDK 或在线 AI 服务；代码不会向开发者发送表格内容或使用事件。你选中的文件本身可能包含个人或机密信息，请谨慎选择导入内容及分享目标。

设备权限

核心功能使用系统文件选择器、应用私有存储和系统分享面板。发布配置未声明相机、照片、麦克风、定位、通讯录、通知或跨应用追踪权限，也不申请遍历全部文件的广泛访问。Android 开发版本为 Flutter 调试声明了 INTERNET 权限，该声明位于 debug／profile 配置，未放在主应用清单中。

网络与第三方服务

应用没有自营网络服务。你选中的文件提供者可能先从其云服务取回文件，再交给 ASTFX。系统备份、设备迁移、应用商店分发及系统诊断可能按各自设置和政策独立处理相关信息。本静态网站没有分析、广告、远程字体或第三方脚本，仅在浏览器 localStorage 中保存语言选择。网站部署后，托管方可能为传送页面而处理 IP 地址和请求信息；正式域名、托管方及日志配置仍须在发布前确认。若你主动发送支持邮件，邮件服务商和收件人会处理你发送的内容，请避免附带敏感表格内容。

存储、保留与删除

应用私有文档目录中保存一个项目，直到被另一个项目替换、在应用内移除，或卸载时由操作系统处理其私有数据。保存时使用临时文件，并保留上一个有效项目的本地恢复备份。移除项目也会删除临时保存文件和本地备份。偏好设置保留到应用数据被移除。系统设备备份或云端设备备份可能按你的设置保留独立副本；本地恢复备份并非开发者云服务。ASTFX 不会覆盖或删除你从文件提供者选择的原文件。

导出与共享

只有在你请求导出后，ASTFX 才在专用临时导出目录生成 CSV 与 Markdown 文件，并交给系统分享面板。报告包含文件信息、数量、质量分和操作摘要，不包含完整原始行；仍有问题时，CSV 标记为草稿。分享目标由你选择，目标方控制其副本和后续处理；分享面板的完成结果不等于某个外部服务已保存文件。应用会在分享返回后尝试删除暂存文件，并在下次启动或导出时重试清理。移除本地项目不会删除已经保存或发送到其他位置的副本。

儿童隐私

应用不要求填写年龄、出生日期、儿童档案或账号。若儿童使用应用，家长或监护人应关注所选文件中的个人信息，并监督分享行为。面向的商店受众和年龄分级仍须在发布前单独确认。有关主动发送给支持邮箱的信息，可通过下方联系方式咨询。

政策变更

实现或数据处理方式改变时，应更新本政策。正式发布的版本须标明生效日期和运营主体。导入或分享敏感文件前，请阅读当前政策。有疑问或本地数据相关请求可联系支持邮箱；开发者无法访问仅保存在你设备中的项目。
