# RhinoSmart V1.0 开发步骤计划

> 计划版本：v1.5  
> 编制日期：2026-08-17  
> 需求基线：`docs/PRODUCT_SPEC.md` v0.2（2026-08-17）  
> 当前状态：M8 实现与自动化验收已完成；CloudKit 双真实设备、iOS 15 Widget 与 M8 真实运行验收待补录，M6/I5 及 M1、M5 的历史手工证据仍未关闭
> 目标平台：Flutter 主应用，首发 iOS 15+；Android 暂缓

## 1. 计划目标

本计划用于把产品规格拆解为可执行、可验收的开发步骤。V1.0 的交付目标是完成以下闭环：

```text
输入或扫描当地价格
  -> 使用在线、缓存或手动参考汇率换算
  -> 比较支付方式预计成本并检查 DCC
  -> 保存消费及计算行程预算
  -> 补录实际入账金额
  -> 在本地离线使用，并可选择通过 iCloud 同步
  -> 通过 Widget 查看摘要，通过 CSV/PDF 导出数据
```

本计划不包含 V1.1、V1.2 功能，例如锁屏 Widget、Siri/快捷指令、Share Extension、高级筛选、行程总结、自动校准建议和多人均摊。

## 2. 执行前提与边界

1. 中英文正式展示名均为 RhinoSmart；Bundle ID、App Group ID、CloudKit Container ID 保持现有集中配置；业务代码、路由和数据库表名仍不得硬编码这些平台标识。
2. iOS 15 是 Runner、Widget Extension 及原生能力的统一最低版本。
3. Flutter 负责页面、状态、计算、数据库、网络、导出和主要业务逻辑；Swift 仅负责 Vision OCR、CloudKit、App Group/Widget 和系统分享能力。
4. 本地 Drift/SQLite 是事实源，CloudKit 是增量同步层。无 iCloud 或同步失败不能阻断本地功能。
5. 金额和汇率必须使用十进制方案或最小货币单位存储，禁止使用普通二进制浮点数作为最终账务精度。
6. 票据图片保存在应用私有目录，V1.0 不跨设备同步原图。
7. Frankfurter v2 是首版市场参考汇率源；支持币种以接口返回为准，产品文案使用“参考汇率”而不是“实时汇率”。
8. 创建工程时再选择兼容 iOS 15 的当前稳定依赖版本，并由 lockfile 固定；本计划不预先锁死版本号。

## 3. 总体开发顺序

```text
M0 技术决策与验收基线
  -> M1 工程与应用骨架
  -> M2 金额、数据库和核心领域模型
  -> M3 汇率、缓存与离线能力
  -> M4 换算、支付成本和 DCC
  -> M5 行程、预算和账本
  -> M6 OCR 扫描链路
  -> M7 CloudKit 同步与 Widget
  -> M8 导出、国际化、隐私与异常收口
  -> M9 全量验收与发布准备
```

关键路径为 M0 → M1 → M2 → M3 → M4 → M5 → M8 → M9。M6 可在 Pigeon 和金额解析契约稳定后与 M5 并行；M7 可在同步元数据、数据库迁移和 App Group 契约稳定后并行，但必须在 M9 前完成双设备和真机验收。

## 4. 全局完成定义

每个任务只有同时满足以下条件才可关闭：

- 实现范围与任务卡一致，没有顺带加入 V1.1/V1.2 功能。
- 业务逻辑有单元测试；数据库、网络、同步等边界有相应集成或契约测试。
- 所有面向用户的文本均来自 ARB，简体中文和英文均可展示，缺失翻译回退英文且不显示开发键名。
- 所有金额、日期、币种和汇率来源状态符合 Locale 与产品文案约束。
- 离线、空状态、失败、重试、权限拒绝和数据缺失路径都有可恢复行为。
- 无卡号、CVV、身份证、银行登录信息或票据原图被发送到日志、分析服务或汇率服务。
- 完成静态检查，并按任务性质补充单元测试、构建、模拟器、真机、双设备、视觉或发布证据。
- 修改支付方式或汇率配置不会改变历史消费保存的快照。

证据必须分层记录：静态检查或单元测试通过不等同于 iOS 构建、模拟器、真机、CloudKit 双设备、OCR 识别、Widget 刷新或发布成功。

## 8. 主要风险与控制措施

| 风险 | 影响 | 控制措施 |
| --- | --- | --- |
| V1.0 范围过大 | 延期或关键链路质量不足 | 严格冻结 P0；V1.1/V1.2 不提前实现；按增量验收 |
| 金额精度或汇率方向错误 | 直接损害产品可信度 | 先完成 Money 核心；表驱动测试；每笔保存快照 |
| 公共汇率服务不稳定 | 在线换算失败 | 缓存、手动汇率、退避、批量请求和可替换 Repository |
| OCR 多 Locale 误判 | 错误金额进入比较 | Swift 只识字；Dart 统一解析；所有候选可编辑；失败回退 |
| CloudKit 冲突或墓碑错误 | 数据丢失或删除记录复活 | 本地优先、幂等同步、稳定 UUID、墓碑、实际金额冲突提示、双设备测试 |
| Flutter 与原生契约漂移 | Runner 或扩展构建失败 | Pigeon 单一 schema、生成一致性门禁、版本化 DTO |
| Widget 读取主库 | 迁移冲突或扩展崩溃 | 仅写最小只读 App Group 快照，Widget 不访问 Drift |
| Apple 标识与签名材料不一致 | 签名、CloudKit 和上架受阻 | 正式标识集中配置；以 distribution profile 的 Team、Bundle ID 和 capabilities 做最终校验 |
| 免责声明或 provider 条款不完整 | 审核和合规风险 | 发布前复核底层数据条款、署名、隐私政策和商店文案 |
| 只凭构建结果宣布完成 | 运行时缺陷漏检 | 分开记录静态、测试、构建、模拟器、真机、双设备、视觉和发布证据 |
