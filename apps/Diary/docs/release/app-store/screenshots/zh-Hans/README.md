# EchoPage App Store 预览图

本目录包含简体中文 App Store 预览图，界面由 Diary 实际 Flutter Widget 按指定设备尺寸渲染，日记文本均为虚构演示数据。

## 设备规格

- `iphone-6.5-1242x2688`：1242 × 2688，RGB PNG。
- `ipad-12.9-2732x2048`：2732 × 2048，RGB PNG。

## 画面顺序

1. `01-capture-this-moment.png`：此刻首页、到期数与待回看线索。
2. `02-revisit-at-the-right-time.png`：现在到期与之后回看的分组。
3. `03-see-how-thoughts-change.png`：原文、未来问题与两次后续回声。

这些文件是视觉与上架素材证据，不代表真机、签名归档、App Store Connect 上传或审核证据。
