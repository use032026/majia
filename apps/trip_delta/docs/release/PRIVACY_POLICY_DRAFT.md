# 旅程差额 / Trip Delta 隐私政策草稿

**仅供本地预检，尚不可发布。** 生效日期、责任主体、联系邮箱、公开 HTTPS 地址、适用地区法律及最终 SDK/网络审计尚未确定；正式文本须由责任主体复核。App 内已支持配置在线 HTTPS 政策及加载失败后重试，但尚未配置正式网址，目前显示本地数据摘要。

## 产品与数据

MVP 无账号、开发者后台、广告、分析、订阅、支付或银行连接。用户手填的旅程名称、类别预算、支出用途/金额/币种/汇率、备注、复盘和语言选择保存在应用私有的本机 Application Support 文件。源码没有上传这些记录的功能；隐私页配置正式网址后会按用户打开页面的操作请求该网页，但不会把旅程记录附在请求中。网页服务可能收到常规访问元数据，具体处理方式需以正式政策和责任主体确认。正式分发前仍须核对最终依赖和实际网络行为。

这些记录可能包含敏感的个人消费信息。应用不会主动把记录发送给开发者。用户可以主动导出 JSON 备份到所选文件位置，或从所选文件位置导入；如果选择云盘或其他文件服务，该备份由用户和所选服务管理。应用没有自动云同步。若用户启用设备系统备份，本机文件**可能进入系统备份**；系统备份由平台与用户设置管理，不等于开发者收集。删除旅程会从当前应用数据中移除该旅程，但既有备份可能仍包含旧副本。未导出备份时，卸载应用可能清除本机记录。

## 权限、分享与汇率

核心流程不请求相机、位置或联系人权限。导入和导出时会打开系统文件选择界面，由用户选择文件或保存位置。用户主动分享旅程回顾卡片时，应用在本机生成图片，通过系统分享界面交给用户选择的应用；系统分享所用临时文件在分享界面关闭后删除。用户主动保存卡片时，应用在 iOS 请求添加照片权限；旧版 Android 可能请求存储写入权限，并将图片写入系统相册。汇率由用户输入，只供预算算术对照，不是实时报价或支付建议。

## 保存、删除与第三方

数据留在应用容器中，直到用户删除对应旅程、卸载应用或设备/备份生命周期结束。应用内可逐笔删除支出或删除整段旅程，删除前二次确认；导入备份时选择“替换全部”也需二次确认。应用无法直接清除用户既有的系统设备备份、主动导出的文件或保存到相册的图片。当前使用 `path_provider` 和 `file_picker` 处理本地文件，`share_plus` 调起系统分享，`gal` 写入系统相册，`webview_flutter` 展示在线隐私页；新增依赖后的最终 Xcode Privacy Report、网络观察和 App Store Connect 隐私回答仍待完成。
