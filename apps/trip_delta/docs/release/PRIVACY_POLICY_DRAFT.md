# 旅程差额 / Trip Delta 隐私政策草稿

**仅供本地预检，尚不可发布。** 生效日期、责任主体、联系邮箱、公开 HTTPS 地址、适用地区法律及最终 SDK/网络审计尚未确定；正式文本须由责任主体复核。App 内仍只有简短说明，正式版须增加可打开的公开隐私政策链接。

## 产品与数据

MVP 无账号、开发者后台、广告、分析、订阅、支付或银行连接。用户手填的旅程名称、类别预算、支出用途/金额/币种/汇率、备注、复盘和语言选择保存在应用私有的本机 Application Support 文件。源码没有上传这些记录的功能或网络客户端；正式分发前仍须核对最终依赖和实际网络行为。

这些记录可能包含敏感的个人消费信息。应用不会主动把记录发送给开发者。用户可以主动导出 JSON 备份到所选文件位置，或从所选文件位置导入；如果选择云盘或其他文件服务，该备份由用户和所选服务管理。应用没有自动云同步。若用户启用设备系统备份，本机文件**可能进入系统备份**；系统备份由平台与用户设置管理，不等于开发者收集。删除旅程会从当前应用数据中移除该旅程，但既有备份可能仍包含旧副本。未导出备份时，卸载应用可能清除本机记录。

## 权限、剪贴板与汇率

核心流程不请求相机、位置、联系人或相册权限。导入和导出时会打开系统文件选择界面，由用户选择文件或保存位置。用户主动选择“复制文字总结”时，摘要进入系统剪贴板，并可被系统或用户随后选择的其他应用处理。汇率由用户输入，只供预算算术对照，不是实时报价或支付建议。

## 保存、删除与第三方

数据留在应用容器中，直到用户删除对应旅程、卸载应用或设备/备份生命周期结束。应用内可逐笔删除支出或删除整段旅程，删除前二次确认；导入备份时选择“替换全部”也需二次确认。应用无法直接清除用户既有的系统设备备份或主动导出的文件。当前使用 `path_provider` 和 `file_picker` 处理本地文件；新增依赖后的最终 Xcode Privacy Report、网络观察和 App Store Connect 隐私回答仍待完成。

- 责任主体法定名称、可持续处理隐私请求的联系邮箱、公开 HTTPS 隐私政策和支持 URL。
- 首发地区、法规适用范围、系统备份处理说明及最终商店隐私回答；双语正式文本。
- 最终签名构建的依赖/权限/网络检查结果与政策版本日期。
