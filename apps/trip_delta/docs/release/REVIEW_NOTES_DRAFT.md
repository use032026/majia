## 核心用途

个人旅行者在出发前按住宿、交通、餐饮、体验及其他类别定预算；开始记录后预算基线锁定。旅途中离线录入实际支出及必要的手填换算率；结束时查看各类别的计划/实付差额，写下一次的预算反思，并可预览、分享或保存旅程回顾卡片。完成后可重新打开纠错。无资金转移、金融账户连接、实时汇率或支付建议。

## 审核路径

1. 首次启动无需账号或网络。可在首页切换简体中文/英文并打开“隐私与数据”。
2. 点“新建旅程”，命名并选本位币，在任一类别填入正预算；例如 CNY 300 餐饮，保存计划。
3. 在旅程详情锁定预算，记录一笔 CNY 350 餐饮支出；详情显示该类和总计超 CNY 50。异币种时可手填 `1 支出币种 = 本位币单位` 的汇率。
4. 点“完成并复盘”，可写反思并保存；点“旅程回顾卡片”可预览图片，主动选择分享或保存到相册。可重新打开、编辑/删除支出或删除旅程；删除会出现确认框。无示范凭证和服务端设置。

## 版本与权限

Flutter MVP 1.0.0+1；iOS 最低 15，Android 工程同时存在。应用不请求相机、位置或联系人权限；iOS 保存卡片时请求添加照片权限，旧版 Android 可能请求存储写入权限；分享卡片使用系统分享界面。免费、无广告、IAP、账号及服务端。系统备份可能包含本机应用数据，产品隐私文案已说明。
