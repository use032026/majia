# 旅程差额：MVP 产品简报与验收（2026-09-18）

> 历史范围说明：2026-10-14 已补入逐笔估算核对后完成、按最终支出复用预算、账本筛选及用户主动的 JSON 备份导入导出。以下非目标描述保留 2026-09-18 的原始立项范围；当前功能以根目录 README 为准。

## 范围和假设

目标是为出发前按类别预算的个人旅行者，提供“计划、记录、差额、复盘”闭环。iOS/Android Flutter 离线应用；中文、英文；无账号、后台、广告、支付或分析 SDK。首发中国大陆及英语地区只是评估假设。应用 ID 和品牌尚未确认，不能用于上架。

## 核心模型

- Trip：标题、记账本位币、类别预算（住宿/交通/餐饮/体验/其他）的整数最小货币单位、状态 draft/active/completed、创建/开始/结束时间、复盘文字。
- Expense：标题、类别、原币金额、原币、本位币每 1 原币的手填汇率、折算后金额、时间、可选说明。记录汇率快照，不自动更新历史记录。
- 本地 Repository：应用私有文件，版本化 JSON，写入临时文件后替换；保存成功后才更新界面状态。解析失败应提示且不覆盖源文件。
- 锁定的预算基线在 active/completed 期间不可修改；draft 可改，完成后可重新打开以纠正支出和复盘。

## 页面与动作

| 页面/状态 | 下一决定和主动作 | 数据与可达性 |
| --- | --- | --- |
| 旅程列表/空状态 | 创建一个旅程，或打开已有旅程 | 列表显示状态和计划/实付；长名称换行；本地读失败展示重试 |
| 预算表单 | 填写名称、本位币、每类别预算并保存 | 金额格式检查；保存前可取消；键盘与滚动底部可到达；draft 可修改 |
| 旅程工作台 | draft 开始记录；active 添加支出；completed 查看复盘 | 计划与实付并列、差额、逐笔来源；空支出不伪称结余；可删除旅程需确认 |
| 支出表单 | 输入金额、类别、汇率后保存或取消 | 同币种汇率 1；异币种须手填正数并标明非实时；可编辑/删除 |
| 结束复盘 | 审核类别差额、写复盘并完成 | 展示最大正偏差、记录数；可复制文本总结；可重新打开纠错 |
| 隐私说明 | 了解本地存储与删除边界 | 从首页可达；外部公开 URL 待上架准备 |

内容策略：长标题和类别值换行；金额完整显示；大字下允许纵向滚动；无固定在键盘上方的关键确认按钮。视觉是暖灰底、深青文字及细线对照表，不沿用 RoamSum 或 071 的卡片层级/品牌。

## 功能验收

| ID | 需求 | 验收 |
| --- | --- | --- |
| FR-01 | 建计划 | 可创建 draft；预算之和正确；无效标题/金额阻止保存；取消不留新旅程 |
| FR-02 | 固定基线 | start 后预算不可编辑；完成/重新打开不改变预算 |
| FR-03 | 记支出 | 同币种与异币种换算正确；手填汇率快照持久化；编辑/删除重算差额 |
| FR-04 | 对照总结 | 各类别与总计差额准确；未记支出时明确缺数据；复盘文字保存并可复制 |
| FR-05 | 恢复与删除 | 重启读回；写失败不丢内存已保存状态；坏文件不被覆盖；删除需确认 |
| FR-06 | 可用性 | 中英、深色、大字、小屏、平板、键盘、取消与重进可完成主路径；需实际运行检查 |

## 非目标与限制

不提供自动汇率、银行连接、支付方式建议、OCR、协作、云同步或备份导入。用户手填汇率仅用于算术换算，不能用于支付决策；卸载可能丢失本机数据，系统设备备份可能保留旧记录，产品内须说明。公开隐私/支持 URL、原创图标、品牌权利、真机、签名 Archive、元数据和商店验证均属上架前缺口。
