# Flutter MVP 开发进度

更新日期：2026-10-10
当前版本：`1.0.0+1`

## 已实现

- Flutter 双平台工程，最低支持 iOS 15、Android 14（API 34）。
- 本地 JSON 数据快照与应用支持目录存储；写入先生成临时文件，并保留上一份备份。
- 新用户可删除示例项目；示例删除后不会在下次启动时重新生成。
- 项目创建、编辑、归档、恢复、删除和进度统计。
- 自动箱号、项目内重复校验、删除后不复用编号。
- 手动空白建箱、相机单张登记、系统照片选择器最多 30 张批量登记。
- 每张批量照片复制到应用目录并逐项创建草稿，单项失败不回滚已经成功的记录。
- 连续相机批次、逐箱“保存并下一箱”、房间/标签批量套用，以及进程退出后的未完成批次恢复入口。
- 语音转写形成可编辑备注；设备、语言或权限不支持时可立即回到文字登记。
- 箱子标题、目的房间、当前位置、备注、标签、结构化物品、优先级、搬运状态和异常标记编辑。
- 结构化物品可独立维护名称、数量和备注，支持逐项勾选已拆箱、编辑和删除。
- 最近使用及常用房间、位置、标签模板可在箱子编辑页一键复用。
- 搬家现场连续扫码，可批量推进至已打包/已装车/已到达/已拆箱，提供震动、重复提示和未扫描清单。
- 搬运状态历史记录变更时间及手动/扫码来源，并支持撤销最近一次状态误操作。
- 项目看板支持按待装车、未到达、未拆箱和疑似遗漏直接多选筛选箱子。
- 待实体标记提醒，以及二维码、手写、便利贴和其他方式的独立确认状态。
- 项目内及全局离线包含匹配搜索。
- QR 载荷 `MOVEBOX|v=1|project=...|box=...|code=...`，以稳定 UUID 定位记录。
- QR 扫描、高清 PNG、单标签 PDF、A4 批量 PDF、系统分享和打印入口。
- 项目收尾报告自动汇总总箱数、疑似遗漏、损坏、未拆箱箱号和房间分布，生成中英文 A4 PDF 并调用系统分享。
- 收尾报告内置 Noto Sans SC 字体资源，确保离线生成的中文 PDF 可正确显示；字体许可证随源码保留。
- “标签已导出”和“实体标记已确认”分别记录；取消分享/打印不会标记为已导出。
- CSV 导出；schema v2 ZIP 备份包包含 JSON、照片、清单和 SHA-256 校验和，跨目录恢复照片并报告缺图；兼容 schema v1 JSON。
- 设置页提供可配置的公开隐私政策 URL、支持邮箱和运行时版本号；真实 URL/邮箱仍需发布构建注入。
- 简体中文/英文 Flutter 文案，iOS 权限用途和双平台应用名称本地化。
