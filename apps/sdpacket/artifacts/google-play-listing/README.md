# Google Play listing assets

The eight phone source captures in `source/` were captured from the actual
KIFXPRO Android app running on a Pixel 7 API 35 emulator at 1080 x 1920 on
2026-10-10. English and Simplified Chinese use matching app states with the
app's own locale setting.

`preview-spec.json` renders four screenshots for each locale plus the two
brand-led 1024 x 500 feature graphics. The feature graphics contain no app UI,
device frame, price, ranking, badge, or duplicated launcher icon.

`icon-512.png` is a 512 x 512 RGBA resize of the repository's production
KIFXPRO icon. No store upload or Play Console mutation is performed here.
