## Product and account model

微成 · Steady21 is an offline-first behavior-experiment journal. It has no account system, app-operated backend, cloud sync, advertising, analytics, in-app purchase, or external digital purchase flow in this MVP.

## Data handled

Users may enter experiment titles, cues, standard and minimum actions, daily completion status, obstacles, recovery choices, milestone decisions, and free-text notes. This content is stored only in a JSON file inside the app sandbox. The app itself does not transmit it to a developer server or third party.

The app is not designed to request or process health records, precise location, contacts, photos, camera data, financial information, government identifiers, or children’s data. Users should avoid placing unnecessary sensitive personal information in free-text fields.

Device-level backup behavior is controlled by the operating system and user settings. This MVP has no independent backup, export, sync, or device-transfer feature. Uninstalling the app, changing devices, or deleting data may cause permanent loss.

## Permissions and network behavior

The current source requests no sensitive system permission and contains no product network client. The final Archive inventory includes Flutter and `path_provider_foundation`; no analytics, advertising, account, payment, or remote storage SDK was found in the reviewed dependency set.

## Collection, tracking, sharing, and third parties

Based on the reviewed source and unsigned Archive, the app does not collect data as defined by App Store privacy disclosures, does not track users, and does not share user content. Final App Store Connect answers must be rechecked against the exact signed build and every final SDK.

The reviewed Archive contains valid privacy manifests for Flutter and `path_provider_foundation`. They declare no collected data or tracking; Flutter declares approved reasons for file timestamp and system boot time required-reason API categories. A final Xcode Privacy Report is still required before submission.

## Retention and deletion

Records remain locally until the user deletes an experiment, chooses “Delete all local data,” or removes the app. “Delete all local data” removes experiments and entries but retains the selected app language. Deleted app records cannot be restored inside this MVP.
