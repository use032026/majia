## 产品论点

- 目标用户：收入来自兼职、项目款或奖金而有波动，拒绝连接银行，但需要为一个重要目标持续储蓄的中英文个人用户
- 昂贵问题：固定周/月储蓄计划默认收入稳定；当用户少存、跳过或临时取出时，普通储蓄罐只显示落后百分比，不能给出透明可选的恢复路径，也会让计划修改覆盖过去承诺
- 产品承诺：用一个专注目标把计划与实际分开记录；每次波动后给出保持日期、保持周额或自定周额的可解释恢复方案，并保留全部计划版本，不声称移动、托管或自动储蓄真实资金
- 核心闭环：创建专注目标与可承受周额 -> 记录已存、取出或跳过及原因 -> 对照当期计划识别提前、正常或需要恢复 -> 选择恢复策略并预览新周额/日期 -> 保存新计划版本且不改写历史 -> 在本地时间线复盘并复制摘要
- 耐久输出：设备本地的储蓄事件与计划版本时间线，以及可复制到其他应用的中英文纯文本复盘摘要

## 非目标

- 不连接银行、不发起存款/取款/转账、不托管资金，也不提供投资、信贷、收益或财务建议。
- 不加入账号、云同步、社交、广告、订阅、排行榜、AI 建议、通知或自动化扣款。
- 不把多目标数量、罐子皮肤、3D 动画、进度环、52 周或 100 信封挑战当作差异化。
- 不复制 Loot 或其他产品的名称、品牌、截图、3D 钱罐、文案、插画、音效或页面层级。
- MVP 仅支持一个当前专注目标；完成后可永久替换为新目标，但不支持多目标并存或历史归档。文件级备份/恢复、组件和快捷指令延期。

## 信息架构与状态

1. 空状态：说明“只记录、不移动真实资金”，主操作为创建一个专注目标。
2. 创建目标：名称、货币符号、目标金额、已存金额、目标日期和当前可承受周额；实时提示计划是否可行。
3. 节奏页：计划/实际双轨、当前差额、到期所需周额、下一步以及最近事件。
4. 记录弹层：选择已存、取出或跳过；金额和原因按类型校验；可取消、点遮罩返回并重新打开。
5. 恢复页：只在需要时展示保持日期、保持周额、自定周额三种预览；确认后追加计划版本，不覆盖历史。
6. 时间线页：按时间合并显示金额事件与计划版本，可复制本地复盘摘要。
7. 设置页：中英文、明暗主题、隐私与产品边界、删除全部数据二次确认。

覆盖状态：本地载入、空状态、典型进度、提前、需恢复、已完成、格式损坏恢复、保存失败、离线、取消、重试和删除确认。没有系统敏感权限，因此无权限拒绝流程。

### 导航与状态转移

- 没有目标时显示独立空状态；右上角可切换语言和主题；“创建目标”进入全屏表单，取消返回空状态，成功返回节奏页。
- 有目标时使用三个一级目的地：`节奏`、`时间线`、`设置`。手机为底部导航，宽度不小于 720dp 时改为左侧 NavigationRail；切换目的地不重建控制器或丢失滚动之外的产品状态。
- 节奏页的唯一主操作是“记录本周”。记录成功后留在节奏页；若变为落后，页面出现带文字的“需要恢复”面板和“查看恢复方案”操作，不强制跳转。目标日期已过时，“保持日期”作为说明卡禁用，只提交可执行的方案。
- 恢复方案是从节奏页推入的全屏页面；取消返回节奏页且不变更计划，确认后保存新版本并返回节奏页，同时结果播报可被读屏读取。
- 完成态仍可访问时间线、设置和复制摘要；主操作为“查看复盘”，次操作为“开始新目标”。确认框列明旧目标、事件和计划版本会被永久删除，并在同一界面提供“复制摘要”；用户确认后清除当前目标并进入创建页。MVP 不保留多目标归档。
- 系统返回遵循页面栈；在三个一级目的地按返回退出 App，不把用户送回已提交表单。

### 状态行为规格

| 状态 | 信息 | 主/次操作 | 输入与返回规则 |
| --- | --- | --- | --- |
| 本地载入 | 小型进度指示与“正在读取本地记录” | 无 | 完成后进入空状态或最近一级目的地 |
| 离线 | 不显示错误；设置页持续说明核心功能离线可用 | 正常使用全部核心功能 | 不发起网络请求 |
| 保存失败 | 页面内错误横幅，说明旧数据未改变 | `重试` / `取消` | 保留表单或策略输入；取消回到旧状态 |
| 损坏数据 | 说明本地记录无法读取且未被自动覆盖 | `清除损坏记录` | 其他产品写操作全部锁定；清除需二次确认后回空状态 |
| 过期未完成 | 显示目标日期已过与当前差额 | `查看恢复方案` / `记录变化` | 历史仍可浏览，不自动改日期 |
| 已完成 | 显示已达成、完成日期与计划版本数 | `查看复盘` / `开始新目标` | 开始新目标需显示删除范围与复制摘要入口的破坏性确认；不静默丢失历史 |
| 删除确认 | 明确列出目标、事件和计划版本将被永久删除 | `永久删除` / `取消` | 取消和遮罩关闭不写数据；成功回空状态 |

## 领域模型与数据所有权

| 模型/服务 | 职责 | 数据所有者 | 生命周期与恢复 |
| --- | --- | --- | --- |
| `SavingsGoal` | 目标、货币、金额、创建时间和初始余额 | 用户/本机 | 单一当前目标；删除全部后不可由 App 恢复 |
| `SavingsEvent` | 已存、取出、跳过及可选原因；事件一经创建不被计划调整改写 | 用户/本机 | 随目标保存，按发生时间排序 |
| `PlanVersion` | 生效日期、周额、目标日期和调整原因 | 用户/本机 | 仅追加；当前计划由最后一个版本决定 |
| `PaceCalculator` | 计算计划应达、实际差额、到期所需周额和恢复预览 | App，纯函数 | 不读写存储，可用固定时钟测试 |
| `GoalRepository` | 版本化 JSON 的加载、保存、清除与损坏数据隔离 | App/本机 | 保存失败不提交内存状态；损坏内容回到可解释错误态 |
| `AppController` | 语言、主题、目标状态和保存前后的一致性 | App | 单一所有者；所有变更先持久化成功再通知 UI |

## 功能需求与验收标准

| ID | 需求 | 验收标准 | 证据层 |
| --- | --- | --- | --- |
| FR-01 | 创建专注目标 | 必填名称；金额均以整数最小货币单位保存；目标大于已存；日期在未来；周额大于零；取消不写数据，保存失败可重试 | 单元测试 + Widget + 运行态 |
| FR-02 | 计算节奏 | 使用计划版本的生效区间计算应达金额；实际金额来自事件；目标完成和过期边界可解释；不以浮点数保存金额 | 单元测试 |
| FR-03 | 记录波动 | 已存/取出要求正金额，取出不能让余额为负；跳过不要求金额；取消、遮罩关闭和重开不产生事件或异常 | 控制器 + Widget + 运行态 |
| FR-04 | 恢复计划 | 保持日期、保持周额、自定周额都显示新日期/周额；确认只追加版本；保存失败时旧计划保持有效 | 单元测试 + Widget + 运行态 |
| FR-05 | 时间线与复制摘要 | 事件和计划版本按时间可读；摘要明确“手动记录，不代表银行余额”；复制动作由用户触发且失败有反馈 | 单元测试 + Widget + 真机待补 |
| FR-06 | 本地持久化与删除 | 重启恢复；未知 schema 或损坏 JSON 进入恢复提示；删除有二次确认并清除目标和偏好之外的产品数据 | 单元测试 + Widget + 模拟器 |
| FR-07 | 本地化/无障碍 | 中英文无内部 key；语义标签不依赖颜色；触控目标至少 44pt；2.0× 文字和小屏核心操作可滚动到达；支持明暗主题 | Widget + 模拟器 + 真机待补 |

### 输入与格式策略

- 目标名 1–40 个 Unicode 字符，可换行三行；事件原因 0–120 个字符，在时间线完整换行，不再跳转到详情。
- 货币符号/短码 1–4 个字符，不执行币种换算；用户输入不会因切换语言而翻译或清空。
- 金额最多两位小数，范围 `0.01–9,999,999,999.99`；领域层保存为整数最小单位，负号只用于显示取出事件。
- 中文日期显示 `yyyy年M月d日`，英文显示 `MMM d, yyyy`；金额两种语言都使用分组符，符号与数字分开保留读屏语义。
- 运行中切换语言立即更新导航和系统文案；未提交表单中的名称、金额、日期和原因保持不变。

### 弹层与表单生命周期

- 记录事件使用纵向语义选择（每项含图标、名称和解释），不使用竞品式顶部 Add/Remove 分段 + 中央大金额 + 底部绿色 Done 组合。
- 键盘 Done/收起只隐藏输入法并保留弹层与输入；Android 返回键在键盘可见时先关闭键盘，再次返回才取消弹层。遮罩、下拉关闭和页面返回视为取消；所有非确认关闭均不写数据，重开为干净默认态。
- 含未保存输入时关闭仍不写入；MVP 不显示额外放弃确认，因为输入短且重开明确为空。
- 保存中禁用关闭和重复提交；保存失败恢复关闭能力、保留输入并显示 `重试` 与 `取消`。
- 打开弹层时读屏焦点落到标题，关闭后回到触发按钮；确认结果通过可聚焦状态提示表达。

## 视觉方向

原创的节奏工作台：暖灰纸面、深蓝墨色与珊瑚警示；以计划/实际双轨带、每周检查点和版本时间线为主，不使用 3D 玻璃罐、100 信封网格、竞品插画、品牌、文案或截图布局

首屏的主要决策是“本周是否按计划，以及下一步记录什么”，主操作始终是“记录本周”。视觉采用 `#F5F1E8` 暖灰纸面、`#17324D` 深蓝墨色、`#2E6F6D` 稳定状态、`#D86F52` 恢复状态和 `#F2C66D` 节点强调。计划/实际使用两条有文字标签的水平轨道，不以颜色单独传达状态；提前、正常、需恢复、过期和完成同时使用文字与图标。标题使用系统无衬线字体，不引入第三方字体权利；金额允许换行，目标名最多三行，长原因在时间线完整换行，关键值不使用无解释省略号。手机使用单栏；宽度不小于 720dp 时使用左侧导航，内容最大 1120dp，主栏与摘要栏按 3:2 排列；小于 720dp（包括 iPad 分屏）退回单栏。弹层最大宽 560dp。

### 无障碍与压力矩阵

- VoiceOver 顺序：页面标题 -> 状态文字 -> 计划金额 -> 实际金额 -> 差额/解释 -> 主操作 -> 次要卡片 -> 一级导航；双轨合并为一个语义节点，朗读计划、实际、差额和状态。
- 选中项用 `selected` 语义、文字和图标共同表达；字段错误与保存结果使用 live region；金额按货币符号、整数和小数可理解朗读。
- 触控区域至少 44×44pt；正文与背景、状态文字与背景目标对比度至少 4.5:1；装饰线条不承载唯一信息。
- 支持键盘 Tab/Shift+Tab、Enter/Space 激活、Esc/系统返回取消；弹层焦点被限制在弹层内并在关闭后归还。
- iPhone SE 与 2.0× 时卡片改为纵向、金额允许换行，底部主操作不固定遮挡内容；创建表单、事件原因、自定周额的最后字段和按钮在键盘打开时都能滚动到。
- 压力数据：40 字中英文混合目标名、120 字原因、`9,999,999,999.99`、1,000 条时间线、过期 365 天、保存失败一次后重试。运行态至少检查典型与一组压力数据。

## 已知限制

- 节奏按自然日和 7 日周期估算，不解析工资日、利息、汇率、通胀或银行交易；所有结果是计划辅助，不是财务建议。
- MVP 只支持一个当前目标和单一货币符号；不执行币种换算。
- SharedPreferences 适合小型本地数据；事件达到 1,000 条时只保证可用，不承诺大规模账本性能。
- 剪贴板摘要不是加密备份；卸载或设备损坏可能导致数据丢失。
- 产品名、Bundle ID、签名、公开隐私/支持 URL、App Store Connect 元数据、真机与辅助功能仍需独立证据。
