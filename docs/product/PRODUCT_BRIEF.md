# EchoPage 产品简报与 MVP PRD

版本：1.0（2026-09-30）
范围：Flutter MVP + 独立功能审核 + iOS App Store 预检；不上传、不提交。

## 产品论点

- 目标用户：会写日记却很少回看、希望看清一段想法如何变化的中英文个人记录者。
- 问题：普通日记把每次书写变成互不相连的存档；当下的问题、担心或期待很少在之后被重新看见。
- 承诺：把一篇日记变成一次可回访的自我对话。
- 核心闭环：写下当下 → 留问题并安排回看 → 重新阅读 → 补写回声 → 关闭或 7 天后继续。
- 耐久输出：应用沙盒中的一条前后线索，包含原文、问题、多次回声、变化标记和状态；用户可主动复制为纯文本。应用不把内容发送到开发者服务，系统级备份边界见下文。

## 产品与数据边界

- 平台：Flutter iOS/Android；iOS 目标最低版本 15.0，当前本机无 iOS 15 runtime。
- 首发假设：中国大陆与英文商店本地化可用地区。
- 语言：简体中文、英文，可跟随系统。
- 免费，无 IAP、广告、账号、后台、社区、分析或远程配置。
- 无运行时权限，不主动联网。
- 日记可能包含私人内容，但产品不要求身份、健康、金融、儿童、位置或通讯录数据，不作心理或医疗承诺。
- 数据保存在应用 Documents 沙盒的 JSON 文件；保存前写 pending，保留上一版 backup。主文件损坏时只读 backup 并显式提示；主/备均不可读时锁定编辑，避免用空数据覆盖。
- 单篇删除先进入最近删除，可恢复；永久删除和清空全部必须二次确认。
- 剪贴板只在用户主动选择“复制前后记录”时写入；应用不提供开发者自有的云同步、自动备份、文件导入或跨设备恢复。
- iOS/Android 的系统级设备备份、iCloud/Google 备份、设备迁移与恢复可能包含应用沙盒数据，取决于操作系统与用户设置；开发者无法读取或删除这些系统备份。因此“永久删除/清空全部”只承诺净化当前安装中的 current、pending 与应用内 backup，不承诺清除历史系统备份。

## 非目标

- 图片、语音、位置、天气、通知、日历视图、生物识别和加密导出延期。
- 不加入模板、信纸、贴纸或统计看板来增加功能数量。
- 不复制参考产品品牌、文案、截图、图标、社区命名或页面层级。

## 信息架构与状态

1. `此刻 / Now`：看到到期数量、开放线索与最近页面；主操作“写下此刻”。
2. `编辑页`：标题可选，正文必填，选择当下色调；未来问题可选。填写问题后选择 3/7/30 天回看。
3. `回看 / Revisit`：把到期与未来回看分组；点击进入详情。
4. `详情`：完整原文、未来问题、所有回声和状态；可编辑、复制、补写回声或移到最近删除。
5. `回声弹层`：后记必填，选择“相同/更清楚/方向改变/可放下”，关闭线索或 7 天后继续；取消不写入。
6. `线索 / Threads`：搜索标题、正文、问题和回声，筛选全部/等待/完成，进入最近删除。
7. `设置`：语言、外观、本地隐私说明、最近删除和清空全部。

覆盖状态：初始载入、空、典型、长内容、到期、未来、关闭、搜索无结果、保存失败、主文件备份恢复、主/备均损坏锁定、编辑取消、弹层取消与重开、软删除/恢复、永久删除和清空确认。

## 领域模型与数据所有权

| 模型/服务 | 职责 | 数据所有者 | 生命周期与恢复 |
| --- | --- | --- | --- |
| `DiaryEntry` | 原文、色调、未来问题、回看日期、关闭/删除状态 | 用户 | 创建后保持稳定 ID；编辑不重建线索；软删除可恢复。 |
| `DiaryEcho` | 某次回看的后记与变化标记 | 用户 | 附着于 Entry；保存成功后才提交；可随 Entry 导出/删除。 |
| `DiarySnapshot` | Entries 与语言/主题设置的 schema v1 快照 | 用户 | 本地 JSON；不支持未知 schema 静默降级。 |
| `FileDiaryRepository` | current/pending/backup 读写与恢复 | 应用代用户保管 | current 损坏回读 backup；全部损坏抛错并锁写。 |
| `DiaryController` | 核心状态机与 save-before-commit | 应用 | 仓库保存失败时内存状态不改变；所有写操作可观察失败。 |

## 功能需求与验收标准

| ID | 需求 | 验收标准 | 证据层 |
| --- | --- | --- | --- |
| FR-01 | 创建与编辑 | 正文空值被 UI 和控制器拒绝；取消不写入；保存失败不改变既有内存状态。 | 控制器 + Widget + 运行态 |
| FR-02 | 回看状态机 | 有问题的条目可到期、补写回声、关闭或续期；稳定 ID 与历史回声保留。 | 单元 + Widget |
| FR-03 | 搜索与重找 | 搜索覆盖标题、正文、问题、回声；全部/等待/完成筛选可组合。 | 单元 + Widget |
| FR-04 | 删除与恢复 | 单篇软删除后不出现在活动列表，可恢复或永久删除；清空必须二次确认。 | 控制器 + Widget；完整危险确认视觉矩阵待补 |
| FR-05 | 本地可靠性 | 当前文件损坏时从上一版备份恢复并提示；当前和备份均损坏时锁写。 | 文件单元 + Widget |
| FR-06 | 耐久输出 | 用户主动复制时包含原文、问题、每次回声的日期与变化标记；无自动外传。 | 静态 + 平台通道失败 Widget；真实剪贴板接收端待补 |
| FR-07 | 本地化与外观 | 中英文无内部 key；系统/浅色/深色设置持久化。 | Widget + 模拟器 |
| FR-08 | 可达性与响应式 | 触控目标使用 Material 控件；关键正文在详情完整可读；小屏 3.2× 字体路径无异常；iPad 内容宽度受限并居中。 | Widget + 模拟器；VoiceOver 真机待补 |

## 页面视觉验收

| 页面/状态 | 主要决定 | 必须可见或可到达 | 长内容策略 | 目标矩阵 |
| --- | --- | --- | --- | --- |
| 此刻空/典型/到期 | 写新页，或选择到期线索 | 到期数、开放数、主操作、完整卡片入口 | 卡片可截断预览，但详情完整；全页可滚动 | iPhone SE/大屏/iPad，中英，明暗，大字 |
| 编辑器 + 键盘 | 保存、取消、是否留未来问题 | 正文、问题、回看日期、保存按钮 | 多行输入和全页滚动；键盘 `adjustResize` | 小屏中英、键盘、12k 字符上限 |
| 详情 + 回声弹层 | 回答问题并关闭或续期 | 完整原文/问题/回声、取消/保存、删除/复制 | 详情和 sheet 均可滚动，底部考虑键盘 inset | 中英、明暗、大字、dismiss/reopen |
| 线索与最近删除 | 找回、恢复或永久删除 | 搜索、筛选、恢复、危险操作确认 | 搜索结果卡片预览，完整内容在详情 | 典型/无结果/大量条目待性能补测 |

## 已知限制

- 没有加密导入/导出、系统备份控制或跨设备恢复；卸载后的数据行为由平台沙盒/备份设置决定。
- 没有通知，用户需主动打开 App 查看到期回看。
- 尚未完成物理设备、VoiceOver/TalkBack、iOS 15 runtime、生命周期压力、低存储和大数据集测试。
- Bundle ID 为 `com.example.diary`，工作名未做商标/名称可用性确认，公开隐私/支持 URL 和 App Store Connect 元数据均不存在。
